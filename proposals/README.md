# proposals/ — งานที่เตรียมไว้แต่ยังไม่ใช้

## pvp-pair-cooldown.patch
พักแรงการโจมตีผู้เล่นต่อเป้าหมายคนเดิม (ซอมบี้ตีเป้าหมายเดิมซ้ำได้ทุก 20 วินาที; มนุษย์ไม่จำกัดต่อคู่) — rules `attacks` + `users/{uid}/lastTgt` + ฝั่งเกม + เทสต์ `tests/emulator/pairrules.js` (ผ่าน 10 กรณี ตอนที่เขียน)
- **ยังไม่ปล่อย** โดยตั้งใจ: รอตัดสินใจเรื่องสมดุล/ประกาศผู้เล่นก่อน (ค่า 20 วินาทีมาจากการจำลองด้วยสเตตัสที่สมมติ ไม่ใช่ข้อมูลจริง — ดูข้อสรุปว่าค่าเดียวแก้ไม่ได้ทั้งต้น/กลาง/ปลายเกมในบทสนทนาที่ทำงานนี้)
- ใช้: `git apply proposals/pvp-pair-cooldown.patch` (ต้องเผยแพร่ rules หลัง merge เสมอ ไม่งั้นผู้เล่นที่อัปเดตเกมแล้วโจมตีไม่ได้ชั่วคราว) แล้ว `node bump.js` และเพิ่มรายการใน `changelog.json`
- ถ้า `git apply` ฟ้อง conflict (ไฟล์เปลี่ยนไปแล้ว) ให้ใช้ `git apply --3way` หรือไล่ตามตัวแพตช์ — โค้ดสั้น (ฝั่งเกม ~15 บรรทัด, rules 2 จุด)
